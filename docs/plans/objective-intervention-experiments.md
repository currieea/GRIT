  corrected MatchDG predictor is generalized to `FactorizedLinearProbeAlgorithm`;
  `MatchDgAlgorithm` remains a positive-strength compatibility wrapper.
- `*_consistency` remains prediction consistency. New representation/control IDs are
  routed explicitly; candidate and algorithm fields distinguish their strengths and
  record width. New objective version is `factorized-pairs/v1`.
- Fishr statistics use final-classifier inputs with the representation graph intact.
  Its reset includes both layers. IRM/V-REx scale the representation term with the
  complete objective. Pair-free controls have disabled pair configuration/lineage;
  control-only CMNIST caches do not read pair arrays, and Waterbirds execution does
  not open the pair manifest. The inherited planner still verifies the shared
  prepared-artifact manifest inventory for every method, including vanilla.

  collapsed-only restores cannot continue factorized updates. Exact optimizer,
  sampler and Fishr EMA resumption is not provided (tasks restart as before).
- Every factorized run writes epoch scaling diagnostics locally and mirrors them to
  optional W&B. Its selected checkpoint retains the selected diagnostic values.
- Eight new `*-representation-interventions-search.yaml` configs use fresh
  `*-interventions-representation-v1` roots, width 32 and independent strengths.
  Verified budgets are 224 ERM / 896 per other row, 2,912 candidates per dataset.

  against branch starting commit `cf4dc659b1b1`, including MatchDG and old matrix grids.
