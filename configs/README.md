# Experiment configurations

Validated experiment settings will live under the dataset-specific `cmnist/` and
`waterbirds/` directories. They are intentionally empty in the package scaffold: the
proposed Milestone 3 typed configuration contract is documented in
[`../docs/contracts.md`](../docs/contracts.md) and awaits user approval before executable
configurations are added.

The YAML fragments in the experiment protocols are illustrative scientific contracts,
not files to copy into this directory without validation.
